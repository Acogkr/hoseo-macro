# hoseo-macro

개인적인 학습 목적으로 만든 비공식 프로젝트입니다. 사용 중 발생하는 계정 문제, 수강 기록 누락 및 그 밖의 손해에 대해 개발자는 책임지지 않습니다. 중요한 수강 기록은 반드시 LMS 원본 사이트에서 직접 확인하세요.

## 설치

Python 3.10 이상과 Google Chrome이 필요합니다.

```bash
pip install git+https://github.com/Acogkr/hoseo-macro.git
hoseo-macro
```

## 업데이트

```bash
pip install --upgrade git+https://github.com/Acogkr/hoseo-macro.git
```
